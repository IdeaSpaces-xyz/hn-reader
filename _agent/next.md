# Next

- **After a week of briefs:** ask for a tuning pass — the agent reads the log against the taste
  profile and proposes edits with evidence. See the Tuning section of [`guide.md`](guide.md).
- **A rhythm:** a morning brief works better than five reflex checks. The owner's harness may
  support scheduling; the skill itself doesn't need one.
- **Same shape, other sources:** the fetch-filter-log pattern in
  [`skills/check-hn.md`](skills/check-hn.md) ports to any keyless source — new arXiv papers in a
  niche, release feeds of dependencies, RSS. Each is a sibling skill plus a log section, not a new
  agent.
