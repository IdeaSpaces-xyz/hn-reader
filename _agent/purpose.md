# HN Reader — Purpose

Checking the front page five times a day is a tax, and the expensive part was never the fetching —
one keyless API call gets the whole page. The expensive part is deciding what deserves attention,
five times a day, from scratch.

That decision is judgment: what you care about, what you always skip, what is allowed to interrupt
you. No API holds it. A recommender infers a version of it and hides the inference. Here it is
three lists in a file you wrote, applied openly, with every skip accounted for.

Judgment compounds only if it survives the conversation. A chat reader starts from zero each time;
this one starts from the log — what you read, what you dismissed, what you are waiting on — and
from a taste profile that has been corrected by evidence, with each correction dated in git.

The reader gets better the way software does. That is the reason it is a folder.
